02

MUST-KNOW FORMULAS

memorize these 8 tonight

Freezing Point Depression

ΔTf = Kf × m where m = moles of solute / kg of solvent → m = ΔTf / Kf → Molar mass = (w × 1000 × Kf) / (ΔTf × W)

Nernst Equation (298 K)

E_cell = E°_cell – (0.0591 / n) × log([products]/[reactants]) E°_cell = E°_cathode – E°_anode

First-Order Kinetics

t = (2.303 / k) × log([A]₀ / [A]) Half-life: t½ = 0.693 / k (independent of concentration)

Packing Efficiencies

SC = 52.4% → 1 atom/cell, r = a/2 BCC = 68% → 2 atoms/cell, r = (√3 × a)/4 FCC/CCP/HCP = 74% → 4 atoms/cell, r = a/(2√2)

Adsorption: Freundlich Isotherm

x/m = k × P^(1/n) (1/n between 0 and 1) Log form: log(x/m) = log k + (1/n) log P
03

MNEMONICS & SHORTCUTS

lock these in memory
PACKING EFFICIENCY — "SBF / 52-68-74"

Simple cubic = 52%  |  BCC = 68%  |  FCC/HCP = 74%
Mnemonic: "Some Bad Friends: 52, 68, 74"

OXIDATION STATES — 1st Transition Series

Max O.S. = Mn (+7) via MnO₄⁻. After Mn, extra stability of ½-filled d⁵ / full d¹⁰ explains drops.
Order of common states: Sc(+3), Ti(+4), V(+5), Cr(+6), Mn(+7), Fe(+3), Co(+3)…

IUPAC COORDINATION NAME ORDER

"A Lonely Cat Never Plays Outside"
Anion ligands first → Letter order (alpha) → Cation metal → Name metal → Prefix → Outer ion
Actual rule: anionic ligands (-o), neutral, then metal name + oxidation state in Roman numerals

NAMED REACTIONS — Quick Recall

Kolbe's: Phenol + CO₂ (NaOH, pressure) → Salicylic acid (Na salt)
Reimer-Tiemann: Phenol + CHCl₃ + NaOH → o-hydroxybenzaldehyde (CHO group introduced)
Cannizzaro: Aldehyde with NO α-H + conc. NaOH → acid + alcohol (disproportionation)
Clemmensen: C=O + Zn-Hg + conc. HCl → CH₂ (reduces carbonyl to methylene)

AMINES — BASICITY ORDER

In water: 2° amine > 1° amine > 3° amine > NH₃ > aniline
(3° loses due to steric hindrance on solvation; aniline resonance delocalizes lone pair → very weak base)

XeF₄ VSEPR TRICK

Xe: 8 valence e⁻. 4 bonds to F + 2 lone pairs = 6 electron domains → octahedral base → square planar shape
2 lone pairs go axial (opposite). Bond angle = 90°.

06

LAST-MINUTE TIPS

prevention & mindset
✅

ALWAYS USE OR OPTIONS

Every Q9–27 has an OR. Scan both before writing. Pick the one where you can score more partial marks, not necessarily the one you "know better."

📐

DRAW STRUCTURES

For XeF₄, organic mechanisms, and coordination complexes — drawing earns marks even if the text explanation is weak. Always label.

🔢

SHOW EVERY STEP

In numericals, write formula → substitution → answer with units. If the final answer is wrong, you still get step marks.

🚫

NEVER LEAVE BLANKS

No negative marking in AHSEC. Write the formula, write a related fact, write the definition — something always scores over nothing.

🎯

SECURE THE EASY 30 FIRST

Q1–8 (8m) + easier SA questions (~22m) = 30 marks for relatively low effort. Lock these before spending time on harder ones.

🧠

MENTAL READINESS

You know more than you think. Anxiety makes you forget. Breathe. Read the full question twice before answering. Don't rush Q1–8.

📝

UNITS & SIGNS MATTER

In electrochemistry: always check sign of E°. In kinetics: always include unit of k. In solutions: use kg not g for molality.

⚡

QUICK WIN TOPICS

Adsorption isotherm (fill in blank), Buna-S monomers (butadiene + styrene), globular protein (haemoglobin) — these are 1-mark guaranteed if revised.
